# AI Booking 完整整合版

本版本已把「自費項目對話資料庫」整合到原有的 A/B/C 老人健檢預約對話中。

## 已完成

- 查詢自費項目與價格
- 找到多個項目時顯示可點選按鈕
- 使用者確認後加入加購清單
- 套組以套組價格計價，避免同一套組重複加總
- 顯示目前加購清單與已知價格合計
- 移除單項、清空全部加購
- 原始價目表沒有有效價格時，明確提示向診所確認
- 保留原本 A/B/C 方案、姓名、身分證、電話、生日流程

## 啟動

```bash
cd ~/Desktop/AI_Booking
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
export GROQ_API_KEY="你的 Groq API Key"
python main.py
```

另一個終端機啟動前端：

```bash
cd ~/Desktop/AI_Booking
python3 -m http.server 5501
```

瀏覽：

- http://127.0.0.1:5501/index.html
- 實驗版：http://127.0.0.1:5501/index_dev.html
- API 文件：http://127.0.0.1:8000/docs

## 對話測試

- `心臟超音波多少錢`
- `我要骨密度`
- `白蛋白價格`
- `好`（把剛才項目加入加購）
- `目前加購`
- `移除第 1 項`
- `清空加購`

## 重要說明

1. `自費項目對話資料庫.json` 是網站實際查詢來源。
2. `自費項目對話資料庫.xlsx` 保留給人工維護與核對。
3. 套組中的單一檢驗項目，例如鈉、鉀、鈣，會回覆套組價格而非誤報單項價格。
4. 甲狀腺套組在原始資料中的公式含錯誤，因此系統不推估價格。
5. 自費資訊僅供項目與價格說明，醫療適用性仍由診所專業人員評估。
