一般預約

預約健檢

流程:
1️. 線上預約登記健康檢查: 網站 / Line / 電話預約 （相關資訊在網頁最下方）
預約需提供資訊：姓名、出生年月日(民國)、身分證字號、電話、健康檢查附早餐(葷素選擇)
2. 失智症篩檢/憂鬱症篩檢：現場拿資料 或 網路下載 後填寫(需在健康檢查當天攜帶)
⚠️ 當天來現場除了可以確認老人健康檢查項目之外，另外可查詢是否符合可做「成人預防保健服務」、「糞便潛血免疫分析」(50-75歲每2年一次)、「B、C型肝炎篩檢」(終身一次)
3. 健檢前須空腹8小時、穿著輕便衣物鞋子、務必攜帶雙證件(健保卡、身分證)
⚠️「受檢資格需至現場經本院確認，若於檢查當天發現資格不符，將無法進行檢查，敬請見諒。」
