# 頤典｜本機測試版 更新說明

## 一、在自己電腦測試

在 VS Code 打開這個資料夾 →「終端機」→「新增終端機」，貼上：

```
bash 本機測試_全部啟動.command
```

會自動打開：
- 後台：http://127.0.0.1:5510/admin.html （密碼 `shanlin2025`）
- 語音預約：http://127.0.0.1:5510/website/index.html

關閉：終端機按 `Control + C`

⚠️ 本機後端連的是**真正的 Firebase**（`website/.env`），測試請用假身分證（例如 `A100000001`），測完到後台刪除。
在「診所設定」改過的資料也會存到真的 Firebase，測完記得改回山林診所。

## 二、這次更新了什麼

### 0. 最新：日曆預約、自費項目選單、預算可以用說的
- **日曆**：自費健檢日曆會把「沒開診的日子、休診日、額滿的日子」變灰色不能點（標示「休診」「額滿」）；
  星期六只會出現上午診。老人健檢的 AI 對話裡也會出現日曆和時段按鈕，說到休診 / 額滿的日子 AI 會告訴原因
- **後台「診所設定」新增**：自費每週門診時段（勾選表）、休診日、每日名額；可預約日期和休診日改成**直接在日曆上點選**
- **自費項目不再塞在聊天框**：電腦版放在聊天框右邊、手機版從下方滑出（可收起）；
  先用白話問「您比較在意哪方面的健康？」（心臟與血管、肺部與呼吸…附「適合：常胸悶、心悸…」），
  每個項目有「可以了解：」白話說明、價格、是否超出預算；不知道選什麼可以看「最多人選的基本套組」
- **預算可以用說的**：按 🎤 說「三千」「兩千五」「一萬五」「預算大概五千左右」都聽得懂

### 1. 診所設定（公版化第一步）
後台登入 → 上方「診所設定」：

| 可以改的 | 會影響哪裡 |
|---|---|
| 診所名稱 | 官網、預約頁、成功頁、後台、LINE 頁面、LINE 機器人 |
| 電話、地址、地址補充說明 | 官網頁尾、確認頁的預約提醒、LINE 機器人 |
| 門診時間 | LINE 機器人回覆 |
| 老人健檢可預約日期 | AI 語音助理問「哪一天」、確認頁的日期選單 |
| 老人健檢可預約時段 | AI 語音助理問「幾點」、確認頁的時段選單（可用半點、下午時段） |

- 沒設定時使用預設值：名稱「頤典診所」，電話、地址、日期、時段沿用原本的資料（已逐像素比對，其他畫面都沒變）
- AI 語音助理的日期、時段辨識改成通用的寫法：「12月15號」「十五號」「8點半」「下午兩點」都聽得懂，
  也修正了原本「12號」會被誤認成「2號」的問題
- 還沒做進設定的（下一步）：健檢方案 A/B/C、65 歲資格、自費價目表、Logo 與主色、LINE 預約頁（liff-appt）的時段

### 2. 首次登入引導＋開通新診所 SOP
- 診所還沒在「診所設定」存過資料時，登入後台會先跳出「👋 歡迎使用頤典預約系統」，引導完成設定；存過一次就不再出現
- 後端網址、LINE LIFF ID 集中到 **`site-config.js`**（兩個分支各一個），開通新診所只要改這個檔
- 開通步驟寫在 **`docs/開通新診所SOP.md`**：Firebase、Railway 環境變數、LINE 設定、測試清單、交付

### 3. 問診題目可自訂
後台「問診題目設定」：新增 BMI、過敏史等題目，AI 問完生日後依序詢問。

### 4. CSS 獨立成檔案
每一頁的樣式都搬到獨立的 `.css` 檔（`css/` 和 `website/assets/css/`），外觀不變。
